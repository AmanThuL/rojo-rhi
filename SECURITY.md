# Security

## Reporting a vulnerability

Report a vulnerability privately through GitHub: on this repository's **Security** tab, choose
**Report a vulnerability**. The report reaches the maintainers only, and the advisory stays private
until a fix is released.

Do not open a public issue for a vulnerability.

Include the release tag, the backend, the operating system and, where you can, a minimal program
that shows the problem.

## Supported versions

Fixes are released on the latest minor version. A vulnerability fix ships as a patch release of that
minor version, and the advisory names the first version that carries the fix.
